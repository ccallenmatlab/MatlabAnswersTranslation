以下のような式から小さな数値を計算しようとしています。

p = -1e17 + sqrt(1e34 + 1e18)

'vpa(-1e17 + sqrt(1e34 + 1e18), 30) を試しましたが、出力は常に p = 0.0 になります。しかし p は正確にゼロではなく、p を含む後続の計算で誤差が伝播してしまいます。丸め誤差を避けるために有効桁数を保持する他の方法はありますか？

実行環境: R2025a MATLAB Online で開く 投票 3
p = -1e17 + sqrt(1e34 + 1e18)
p = 0

倍精度で計算すると、p は実際には正確に 0 になります。

p == 0 % true
ans = logical
   1

なぜ vpa で上手くいかなかったのでしょうか？あなたが vpa を呼び出した方法：

p = vpa(-1e17 + sqrt(1e34 + 1e18), 30)
p = 0.0

この方法では、vpa() が呼び出される入力引数を生成するための計算を倍精度で行い、その倍精度の結果を vpa に渡しています。vpa が呼び出される時点で、p はすでに 0 になっています。

各数値を sym に変換してから計算を行うことができます。こうすることで、MATLAB は計算をシンボリックに実行します。p の表示に根号が含まれていることに注目してください。

x17 = sym(1e17);
x34 = sym(1e34);
x18 = sym(1e18);
p = -x17 + sqrt(x34+x18)
p = (10000000000000000100000000000000000)1/2 - 100000000000000000

次に、そのシンボリックな答えに対して vpa を呼び出し、可変精度演算を使用して評価できます。

vpa(p, 30)
ans = 4.99999999999999987499995984189

良い説明ですね。Symbolic Math Toolbox を必要としない追加のアプローチとして、式を代数的に変形する方法があります。式 -a + sqrt(a^2 + b) に対して、共役で乗除すると b / (a + sqrt(a^2 + b)) が得られ、壊滅的な桁落ちを回避できます。

SL Steven Lord ◆ スタッフ MVP 2026年5月2日 20:37

良い指摘です、James。壊滅的な桁落ちを避けるための式の変形は、追加のツールボックスを必要とせず、ネイティブの倍精度演算で動作するため、可能な場合は最良のアプローチです。
